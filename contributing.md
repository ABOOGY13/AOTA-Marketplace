# Contributing to AOTA Marketplace

Thanks for your interest in contributing!

## 🧩 How to Contribute

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Commit clearly
5. Submit a pull request

## 🐛 Found a bug?
Open an issue and include:
- What happened
- Steps to reproduce
- Expected result

## 🌟 Feature requests
Open an issue labeled *enhancement* and describe:
- What you want added
- Why it’s useful

## 📄 Pull Request Rules
- One feature/fix per PR
- Keep code clear + commented
- Add screenshots if UI changes

Thanks for supporting AOTA Marketplace!
