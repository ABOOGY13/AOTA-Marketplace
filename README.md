# AOTA Marketplace & Raffle Platform

AOTA Marketplace is a community-driven buying, selling, and raffle platform.  
Users can browse products, enter raffles, and securely purchase items through an easy and trusted experience.

---

## 🚀 Features

- 🛒 List items for sale with photos, price, and details  
- 🎟️ Create raffles with limited entries
- 👤 User accounts and login system (planned/coming soon)
- 💳 Secure checkout integration (Stripe/PayPal planned)
- 📱 Mobile-friendly layout
- 📦 Dashboard for sellers to manage listings and raffles
- 🌐 Live deployment on Vercel

---

## 🏗️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (or Next.js if you change)
- **Hosting:** Vercel
- **Payments:** Stripe integration (in progress)
- **Backend:** JavaScript API routes / serverless functions (in progress)
